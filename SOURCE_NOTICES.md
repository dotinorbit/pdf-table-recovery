# Source and licensing notes

## Project contents and license scope

This code-only candidate contains project-origin implementation, synthetic tests, documentation, a checksum and a dependency list. The checker and synthetic tests are preserved from the original utility; the small recovery recipe packages the already-tested boundary settings without embedding expected cell values.

No third-party implementation is vendored. No source-PDF prose, table extracts, real-PDF fixtures, CSVs, rendered pages, benchmark provenance excerpts or expected source-cell strings are included. The source link, file hash, page/row indices and boundary coordinates are factual reproduction metadata. Generated output and the source PDF remain outside this tree.

The implementation and documentation were generated by dot, an OpenAI-powered assistant. It does not grant rights to downloaded PDFs, locally generated source extracts or third-party dependencies. AI authorship does not establish rights in third-party material.
